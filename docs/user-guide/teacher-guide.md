# Teacher User Guide

## Getting Started

### Logging In

1. Open the school portal in your browser
2. Enter your **username** and **password** (assigned by the admin)
3. Click **Sign In**

Your **Teacher Dashboard** loads after login.

---

## Dashboard

The Teacher Dashboard shows a real-time overview of your work:

| Card | Description |
|------|-------------|
| My Classes | Classes assigned to you |
| Today's Attendance | Marked vs. not yet marked |
| Pending Homework | Assignments awaiting student submissions |
| Upcoming Exams | Exams you need to mark |
| Announcements | Latest school notices |
| Quick Actions | Fast links to mark attendance, add homework |

---

## Taking Attendance

This is the most common daily task.

### Marking Class Attendance

1. Go to **Attendance** → **Mark Attendance**
2. Select your **class** from the dropdown
3. The date defaults to today — change it if marking retroactively
4. For each student, tap/click:
   - **P** = Present
   - **A** = Absent
   - **L** = Late
   - **E** = Excused
5. Add **remarks** for absences if needed (e.g., "Sick leave with note")
6. Click **Submit Attendance**

> **Tip:** Use **Quick Attendance** from the dashboard for a faster one-tap interface on mobile.

### Editing Attendance

- You can edit attendance for today only
- For corrections on past dates, request the admin to make changes

### Attendance Reports

1. Go to **Attendance** → **Monthly Summary**
2. Select a class and month
3. View each student's present/absent/late counts and percentage
4. Click **Export CSV** to download the report

## Homework

### Assigning Homework

1. Go to **Homework** → **New Assignment**
2. Fill in:
   - **Class** — which class this is for
   - **Subject** — auto-filtered to your assigned subjects
   - **Title** — short description
   - **Description** — detailed instructions
   - **Due Date** — when it must be submitted
   - **Attachment** — optional file (PDF, image)
3. Click **Assign**

Students see this immediately on their dashboard.

### Viewing Submissions

1. Go to **Homework** → **View Submissions**
2. Select the assignment
3. Each submission is listed with the student name, submission time, and attached file

---

## Timetable

1. Go to **Timetable** in the sidebar
2. Your personal timetable shows your periods, classes, and subjects
3. Use **Print** to get a printed copy

---

## Exams & Marks

### Entering Student Marks

1. Go to **Exams** → **Enter Marks**
2. Select the **exam** and **subject**
3. For each student, enter the marks obtained
4. Click **Save Marks**

> Marks are validated against the exam's maximum marks. Entries above maximum are flagged.

### Viewing Results

1. Go to **Exams** → **Results**
2. View a class-wise or student-wise breakdown of marks and grades

### Report Cards

1. Go to **Exams** → **Report Cards**
2. Select a student and term
3. Click **Print PDF** for a formatted report card

---

## Syllabus Tracking

Track your teaching progress against the planned syllabus:

1. Go to **Syllabus** from the sidebar
2. Select your **class** and **subject**
3. Topics are listed with their completion status
4. Click a topic to mark it as **Completed**
5. Add a note if you want to record the date or any deviations

---

## Fee Information (Read-Only)

Teachers can view fee status but cannot record or modify payments.

1. Go to **Fees** from the sidebar
2. You can see which students have outstanding fees in your classes
3. This helps when following up with parents during meetings

---

## Announcements

### Viewing Announcements

All announcements are visible in **Announcements** or on the dashboard.

### Creating an Announcement

1. Go to **Announcements** → **New Announcement**
2. Set:
   - **Title** and **Body** — the content
   - **Target** — All, Students, Teachers, or Parents
   - **Class** — leave blank to send to all, or pick a specific class
   - **Pin** — pin important notices to the top
3. Click **Publish**

Students and parents receive a push notification immediately.

---

## Parent-Teacher Meetings (PTM)

### Scheduling a Meeting

1. Go to **Meetings** from the sidebar
2. Click **Schedule Meeting**
3. Select the parent, date, time, and add agenda notes
4. The parent receives a notification

### Viewing Upcoming Meetings

Your upcoming PTM schedule appears on the **Meetings** page and on your dashboard.

---

## Discipline Records

1. Go to **Discipline** from the sidebar
2. Click **Add Record**
3. Select the student, incident type, date, and description
4. Choose an action taken (Warning, Parent Notified, Suspension)
5. Click **Save**

Discipline history is visible to the admin and parents.

## Profile & Password

1. Click your name at the top-right
2. **Profile** — view your details
3. **Change Password** — update your password
4. **Sessions** — see where you are logged in; revoke sessions you don't recognise

## Tips for Efficient Use

- **Bookmark** the portal URL — it works best in Chrome or Firefox
- Use **Quick Attendance** (dashboard shortcut) on your phone for faster marking
- Set homework **due dates** 2–3 days ahead to give students time
- Export your **monthly attendance report** at the end of each month for your records
